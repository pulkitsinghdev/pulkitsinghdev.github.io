# Miguel O'Hara / Spider-Man 2099-inspired dark palette

A dark-first interpretation of the suit's midnight, cobalt, scarlet, and ice contrast. No character artwork, logos, or copyrighted suit graphics are used.

| Token | Hex | Usage |
|---|---|---|
| Midnight navy | `#071525` | Main page and section backgrounds |
| Ink navy | `#0A1A30` | Inset surfaces, cards, and device mockups |
| Ice paper | `#E8EEF6` | Main typography and high-contrast details |
| Spider scarlet | `#F0183C` | Primary accent, annotations, focus and emphasis |
| Cobalt blue | `#1769AA` | Secondary accent, navigation and interactive states |

The whole portfolio uses the night-sheet treatment. No alternating light/paper sections are shown. Keep the page predominantly midnight and ink; use cobalt for structure and reserve scarlet for moments that deserve attention.
